# Production hardening

SignFlow now exposes account/RBAC controls, API keys, rate limiting, structured logs, metrics, optional Sentry, model/experiment registry and CSV audit export. `DATABASE_URL` enables managed PostgreSQL in production while local development falls back to SQLite.

The vocabulary endpoint combines built-in demo gestures with user-collected labelled samples and reports whether each class has reached a configurable minimum sample count. Sequence decoding collapses repeated high-confidence predictions into readable tokens. This remains a gesture-recognition portfolio prototype, not a certified natural sign-language translator.
